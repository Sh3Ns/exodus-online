1. BASIC PROFILE STRUCTURE
===============================================================================

{
  "Name": "Bow 2H Mercurial Bleeder",
  "ProficiencyId": 469,
  "Version": 1,
  "Levels": [
    {
      "Perks": [
        {
          "Type": 22,
          "Value": 30,
          "Range": 3
        }
      ]
    }
  ]
}

FIELD              REQUIRED    MEANING
Name               Yes         Readable profile name shown by the client, in order "WeaponName 1H/2H (1 hand 2hands), ItemName".
ProficiencyId      Yes         Unique persistent ID for this weapon profile, never use the same.
Version            Yes         Profile revision number. Normally starts at 1.
Levels             Yes         Ordered mastery stages for this weapon.
Perks              Yes         Choices offered in one mastery stage.
Type               Yes         Perk behavior ID. See the Type table below.
Value              Yes         Perk strength. Its unit depends on Type.
SkillId            Sometimes   Required by Types 3, 25, 26 and 27.
ElementId          Sometimes   Required by Types 9, 13, 31 and 32.
DamageType         Sometimes   Required by Type 4.
SpellId            Sometimes   Required by Type 5.
AugmentType        Sometimes   Required by Type 5.
BestiaryName       Sometimes   Required by Type 6.
Range              Sometimes   Required by Type 22.
Chance             Sometimes   Required by Type 32.

ONE IMPORTANT LEVEL RULE
------------------------

Perks inside the SAME "Perks" array are alternative choices. The player selects
only one choice from that level.

Default Weapon Prof has 7 perks enabled, as you know me i made the module capable to support until 20 perks,
scrollbar added and you can see all of them, EXP aswell goes until the perk 20.
Tooltip will show the max level depending on how many levels ( perks ) has the weapon, if is 5 or if is 20.
If you add a lot of perks i will recommend do not abuse with values otherwise you can kill your server.

This gives three choices, but only ONE becomes active:

{
  "Perks": [
    {"Type": 0, "Value": 25},
    {"Type": 31, "Value": 0.05, "ElementId": 8},
    {"Type": 3, "Value": 2, "SkillId": 7}
  ]
}

If you want all three bonuses to be selectable and active together, put them in
three different Levels:

"Levels": [
  {
    "Perks": [
      {"Type": 0, "Value": 25}
    ]
  },
  {
    "Perks": [
      {"Type": 31, "Value": 0.05, "ElementId": 8}
    ]
  },
  {
    "Perks": [
      {"Type": 3, "Value": 2, "SkillId": 7}
    ]
  }
]

3. PROFICIENCY SKILL IDs
===============================================================================

WARNING: JSON SkillId is a PROFICIENCY ID. It is not the numeric C++ enum value.
Use the first column in proficiencies.json.

SkillId  Name                 Server constant       C++ enum value  Supported
1        Magic Level          SKILL_MAGLEVEL        14              Yes
6        Shielding            SKILL_SHIELD          5               Yes
7        Distance Fighting    SKILL_DISTANCE        4               Yes
8        Sword Fighting       SKILL_SWORD           2               Yes
9        Club Fighting        SKILL_CLUB            1               Yes
10       Axe Fighting         SKILL_AXE             3               Yes
11       Fist Fighting        SKILL_FIST            0               Yes
13       Fishing              SKILL_FISHING         6               Yes
14       Crafting             SKILL_CRAFTING        7               Yes
15       Woodcutting          SKILL_WOODCUTTING     8               Yes
16       Mining               SKILL_MINING          9               Yes
17       Herbalism            SKILL_HERBALIST       10              Yes
18       Armorsmithing        SKILL_ARMORSMITH      11              Yes
19       Weaponsmithing       SKILL_WEAPONSMITH     12              Yes
20       Jewelsmithing        SKILL_JEWELSMITH      13              Yes

SkillId is used by:

Type 3   Adds flat levels to any skill in this table.
Type 25  Uses a combat skill to calculate extra auto-attack damage.
Type 26  Uses a combat skill to calculate extra spell damage.
Type 27  Uses a combat skill to calculate extra spell healing.

Profession SkillIds 14 through 20 are intentionally supported only by Type 3.
They are not valid for Types 25, 26 or 27 because Crafting, Woodcutting, Mining,
Herbalism, Armorsmithing, Weaponsmithing and Jewelsmithing are not combat
damage/healing skills.

Examples:

Add +3 Weaponsmithing:

{
  "Type": 3,
  "Value": 3,
  "SkillId": 19
}

Add 10% of Distance Fighting as flat auto-attack damage:

{
  "Type": 25,
  "Value": 0.10,
  "SkillId": 7
}

If Distance Fighting is 120, this adds:
  120 * 0.10 = 12 flat damage

Add 20% of Magic Level as flat spell healing:

{
  "Type": 27,
  "Value": 0.20,
  "SkillId": 1
}

6. EVERY PERK TYPE
===============================================================================

Type  Constant                          Required extra fields
0     PERK_WEAPON_ATTACK                None
      Flat damage for melee, ranged or wand auto-attacks.
      Value: flat damage, normally 5 to 100.

1     PERK_SHIELD_DEFENSE               None
      Flat reduction from incoming damage.
      Value: flat reduction, normally 2 to 30.
      Current limitation: the server does not verify a shield is equipped.

2     PERK_WEAPON_DEFENSE               None
      Flat reduction from incoming damage.
      Value: flat reduction, normally 2 to 30.
      Current limitation: server behavior is currently the same as Type 1.

3     PERK_SKILL_BONUS                  SkillId
      Adds flat levels to the selected skill while the perk is active.
      Value: whole skill levels, normally 1 to 3.

4     PERK_MAGIC_BONUS                  DamageType
      Adds flat spell damage when the spell element matches DamageType.
      Value: flat damage.
      Current limitation: despite the old client name, it does NOT add Magic Level.

5     PERK_SPELL_AUGMENT                SpellId, AugmentType
      Modifies one spell. Value unit depends on AugmentType.

6     PERK_BESTIARY_DAMAGE              BestiaryName
      Increases damage against a matching Bestiary category.
      Value: decimal percent.

7     PERK_POWERFUL_FOE_DAMAGE          None
      Increases damage against Bosstiary or fiendish monsters.
      Value: decimal percent.

8     PERK_CRITICAL_CHANCE              None
      Adds critical chance to supported outgoing attacks.
      Value: decimal percent.

9     PERK_ELEMENTAL_CRITICAL_CHANCE    ElementId
      Adds critical chance only to matching elemental damage.
      Value: decimal percent.

10    PERK_RUNE_CRITICAL_CHANCE         None
      Adds critical chance to offensive rune damage.
      Value: decimal percent.

11    PERK_MELEE_CRITICAL_CHANCE        None
      Adds critical chance to melee, ranged and wand auto-attacks.
      Value: decimal percent.

12    PERK_CRITICAL_DAMAGE              None
      Adds critical extra damage to all supported attacks.
      Value: decimal percent.
      A proficiency critical already adds 50%; Value is added above that.

13    PERK_ELEMENTAL_CRITICAL_DAMAGE    ElementId
      Adds critical extra damage to matching elemental damage.
      Value: decimal percent.

14    PERK_RUNE_CRITICAL_DAMAGE         None
      Adds critical extra damage to offensive rune damage.
      Value: decimal percent.

15    PERK_MELEE_CRITICAL_DAMAGE        None
      Adds critical extra damage to melee, ranged and wand auto-attacks.
      Value: decimal percent.

16    PERK_MANA_LEECH                   None
      Restores mana equal to Value of damage dealt.
      Value: decimal percent.

17    PERK_LIFE_LEECH                   None
      Restores health equal to Value of damage dealt.
      Value: decimal percent.

18    PERK_MANA_ON_HIT                  None
      Restores a flat amount of mana after a damaging hit.
      Value: flat mana.

19    PERK_LIFE_ON_HIT                  None
      Restores a flat amount of health after a damaging hit.
      Value: flat health.

20    PERK_MANA_ON_KILL                 None
      Restores flat mana after a qualifying Bestiary monster kill.
      Value: flat mana.

21    PERK_LIFE_ON_KILL                 None
      Restores flat health after a qualifying Bestiary monster kill.
      Value: flat health.

22    PERK_PERFECT_SHOT                 Range
      Adds flat auto-attack damage at Range tiles OR FARTHER.
      Distance uses max(abs(dx), abs(dy)).
      Value: flat damage.

23    PERK_HIT_CHANCE                   None
      Adds ranged hit chance through the native proficiency combat bonus.
      Value: decimal percent. 0.05 becomes +5 percentage points.

24    PERK_ATTACK_RANGE                 None
      Adds attack range through the native proficiency combat bonus.
      Value: whole tiles.

25    PERK_MELEE_SKILL_FLAT_DAMAGE      SkillId
      Adds SkillLevel * Value as flat auto-attack damage.
      Value: skill multiplier.

26    PERK_SPELL_SKILL_FLAT_DAMAGE      SkillId
      Adds SkillLevel * Value as flat spell damage.
      Value: skill multiplier.

27    PERK_HEALING_SKILL_FLAT_DAMAGE    SkillId
      Adds SkillLevel * Value as flat spell healing.
      Value: skill multiplier.

28    PERK_ALPHA_STRIKE_DAMAGE          None
      Increases damage while the monster is above 95% health.
      Value: decimal percent.

29    PERK_OMEGA_STRIKE_DAMAGE          None
      Increases damage while the monster is below 30% health.
      Value: decimal percent.

30    PERK_ARMOR_PENETRATION            None
      Currently multiplies physical damage by 1 + Value.
      Value: decimal percent.
      Current limitation: this is not true post-defense armor bypass.

31    PERK_ELEMENTAL_PIERCE             ElementId
      Currently multiplies matching elemental damage by 1 + Value.
      Value: decimal percent.
      Current limitation: this is not true resistance bypass.

32    PERK_HOMING_MISSILE               ElementId, Chance
      Each offensive spell cast rolls Chance once. On success, it fires an
      elemental missile at the first monster hit by that cast.
      Value: character-level multiplier. 2.0 deals 200% of character level.
      Chance: decimal probability. 0.01 means 1%.

9. HOW PROFICIENCY ICONS WORK
===============================================================================

The JSON does not normally contain an "Icon" field.
The client chooses the icon from Type and the extra fields.

MAIN TABLE:

  hellgrave-client/modules/game_proficiency/const.lua

  PerkVisualData = {
    [PERK_WEAPON_ATTACK] = {source = "icons-0", offset = "0 0"},
    ...
  }

"source" selects this image:

  hellgrave-client/modules/game_proficiency/proficiency/<source>.png

"offset" selects one 64 x 64 cell inside that image.

Example:

  source = "icons-0"
  offset = "128 0"

means:

  hellgrave-client/modules/game_proficiency/proficiency/icons-0.png
  crop starts at x=128, y=0 and uses the configured 64 x 64 icon area. X = left/right Y = up/down


ICON SELECTION BY PERK
----------------------

Perk kind                   Client table used             Sprite source
Normal fixed Type           PerkVisualData                source in that entry
Types 3, 25, 26, 27         SkillTypes[SkillId]           icons-7/4/5/6
Type 4 magic boost          MagicBoostMask[DamageType]    icons-8
Type 5 spell augment        SpellAugmentIcons[SpellId]    icons-9
Type 5 small augment mark   AugmentPerkIcons              augment-icons
Type 6 Bestiary damage      BestiaryCategories            icons-3
Types 9 and 13              ElementalMask[ElementId]       icons-2/icons-1
Type 31 elemental pierce    ElementalMask[ElementId]       icons-2
Type 32 homing missile      ElementalMask[ElementId]       icons-2


CUSTOM SKILL ICONS

The profession skill icons are stored in icons-7.png and are used only by Type 3.

Current 64 x 64 icon order:

1. Profession icons:
     Crafting
     Woodcutting
     Mining
     Herbalism
     Armorsmithing
     Weaponsmithing
     Jewelsmithing

2. Sheet used:
     icons-7.png  (Type 3)

   icons-4.png, icons-5.png and icons-6.png remain combat-skill sheets. Profession
   icons must not be added to them because profession skills cannot scale combat
   damage or healing.

3. Add active icons to the first row and their grey/inactive versions to the
   corresponding second row, following the current sheet structure.

4. Change SkillTypes in client const.lua:

   [14] = {name = "Crafting",       imageOffset = "512 0"},
   [15] = {name = "Woodcutting",    imageOffset = "576 0"},
   [16] = {name = "Mining",         imageOffset = "640 0"},
   [17] = {name = "Herbalism",      imageOffset = "704 0"},
   [18] = {name = "Armorsmithing",  imageOffset = "768 0"},
   [19] = {name = "Weaponsmithing", imageOffset = "832 0"},
   [20] = {name = "Jewelsmithing",  imageOffset = "896 0"}

5. Make every affected PNG wide enough for the largest offset plus 64 pixels.
   For offset 896, the image must be at least 960 pixels wide.

6. Keep the inactive row aligned with the same x offsets.


ADDING A NEW FIXED PERK TYPE ICON
--------------------------------

If a new Type is implemented in both server and client:

1. Add its numeric constant to client const.lua.
2. Add the combat behavior to server proficiency.lua.
3. Add its name/description to PerkTextData.
4. Put the 64 x 64 image into an existing/new sprite sheet.
5. Add an entry to PerkVisualData:

   [PERK_MY_NEW_TYPE] = {source = "icons-10", offset = "0 0"}

6. Add formatting logic to proficiency_data.lua if it has custom fields.


ADDING A NEW SPELL AUGMENT ICON
-------------------------------

Add the spell to SpellAugmentIcons in client const.lua:

  [500] = {
    name = "My Custom Spell",
    imageOffset = "192 192"
  }

Then ensure icons-9.png contains that spell icon at the same offset.


===============================================================================
10. CURRENT RUNTIME RULES AND LIMITATIONS
===============================================================================

1. Only selected perks from the currently equipped proficiency weapon are active.

2. The player must meet the item's level and vocation requirements.
   A GOD character may equip another vocation's weapon, but proficiency perks
   remain inactive unless the vocation requirement is met.

3. Outgoing proficiency damage currently applies only against monsters.

4. Flat damage from active perks is combined and applied once to the first
   non-zero primary/secondary damage component.

5. Percentage damage perks stack additively before final damage is calculated.

6. Type 22 Range means that distance OR FARTHER, not only the exact distance.

7. Type 1 and Type 2 currently have the same server reduction behavior.

8. Type 4 currently gives flat elemental spell damage, not Magic Level.

9. Type 30 and Type 31 currently act as matching damage multipliers. They do not
    bypass armor/resistance.

10. The number of Levels controls how many mastery stages the profile can unlock.

11. Restart/reload the server after changing server profile definitions. Keep the
    client JSON synchronized and reload the client module when client data changes.

12. Type 32 rolls once per offensive spell cast, not once per target in an area
    spell. Its extra damage does not recursively trigger proficiency bonuses.
