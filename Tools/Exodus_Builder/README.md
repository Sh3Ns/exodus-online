What is Exodus Builder?
----

Exodus Builder is an editor for creating graphic objects for Exodus Client. You can edit or add new items, outfits, effects or missiles to your client.

Some features:

* Support frame groups.
* It's faster to load or compile your projects.
* Import or export your objects as sprite sheet.
* Support for transparent sprites.
* You're able to cut the imported images.
* Suppor New Categorys from Market.


Supported client versions:
----

* 7.10 - 12.86
* We recommend only use it for Exodus
